# Configurable Reconnect - MC 26.2

This is a minecraft mod that requires Fabric and Fabric API. It adds a "Reconnect"button to the pause screen of the game, only when you are on a multiplayer server. Pressing this buttons will disconnect you back to the server list and then, after a delay, automatically reconnect you. This delay is set to 2 seconds by default, but can be changed by the player.

## FAQ

#### Where can I download this mod as a ready to use file?

The mod is available on Modrinth: https://modrinth.com/mod/configurable-reconnect/versions (if the page is unavailable it is still under review of the modrindth admins)

#### Is there a Forge version?

No, and I currently have no plans to make one. Anyone else willing to convert this mod to Forge is more than welcome to do so, no neeed to message me for permission.

#### What Minecraft versions are supported?

Currently, only 26.2 is oficially supported. I have no current plans to make versions of the mod for older minecraft versions. I do plan to update this mod for future versions, at least 1.26.3, for as long as im personally using this mod or my friends are,

#### Why would anyone need a reconnect button?

Great question! They probably don't!
On a more serious note, I mainly developed this mod as a convenience tool. Our survival server is building a remote enderpearl stasis network, and it uses a relog timing based "recall" device to teleport you back to your personal control hub. It's perfectly posssible to time this manually, but it just felt convinient to do it with one button.

#### Is the mod client- or serversided?

This mod is fully clientside! You can use it on a server without them needing to install anything for you. As always with mods, make sure the server allows you to use it. If you don't, any bans are on you.
